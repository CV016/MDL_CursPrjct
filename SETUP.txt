STEP 1 — Connect to the server with port forwarding
--------------------------------------------------------------------------------

Run this command in your local terminal (Windows PowerShell or Mac/Linux shell).
Keep this terminal open the entire time you are using the app.

    ssh -L 9501:localhost:9501 -L 8000:localhost:8000 -L 5000:localhost:5000 b22bb016@172.25.1.12

What this does:
    localhost:9501  ->  Streamlit UI
    localhost:8000  ->  FastAPI backend  (Swagger docs at /docs)
    localhost:5000  ->  MLflow UI

Once connected you are inside the server. All commands below are run there.


--------------------------------------------------------------------------------
STEP 2 — Find the project folder
--------------------------------------------------------------------------------

The project lives directly in the home directory, not in a subfolder.

    cd ~
    ls

You should see docker-compose.yml and folders like backend/, frontend/, mlops/.


--------------------------------------------------------------------------------
STEP 3 — Attach to the running tmux session
--------------------------------------------------------------------------------

tmux keeps everything running after you disconnect.

    tmux ls                  # list existing sessions
    tmux attach -t 0         # attach to session 0 (or whatever name is listed)

If no session exists, create one:

    tmux new -s app

Inside tmux, open a new window with:   Ctrl+B  then  C
Switch between windows with:           Ctrl+B  then  0 / 1 / 2 ...
Detach (leave everything running):     Ctrl+B  then  D


--------------------------------------------------------------------------------
STEP 4 — Check that containers are running
--------------------------------------------------------------------------------

    cd ~
    docker compose ps

Expected output (all three services should show "running"):

    NAME              STATUS
    ai_doc_mlflow     running (healthy)
    ai_doc_backend    running
    ai_doc_frontend   running

If any container shows "exited" or "starting", see the troubleshooting section.


--------------------------------------------------------------------------------
STEP 5 — Open the app in your browser
--------------------------------------------------------------------------------

With the SSH tunnel from Step 1 still open, visit:

    Streamlit UI   ->  http://localhost:9501
    MLflow UI      ->  http://localhost:5000
    API docs       ->  http://localhost:8000/docs

The backend takes about 2 minutes to load both AI models on first start.
If the UI shows a connection error, wait and refresh.


--------------------------------------------------------------------------------
PULLING NEW CODE AND REBUILDING
--------------------------------------------------------------------------------

When someone pushes a code update to GitHub, sync it to the server:

    cd ~
    git fetch origin && git reset --hard origin/newPlan

Then rebuild only the service that changed.

    # Frontend change (app.py)
    docker compose build frontend-ui
    docker compose up -d

    # Backend change (main.py, requirements.txt)
    docker compose build backend-api
    docker compose up -d

    # Both changed
    docker compose build
    docker compose up -d

docker compose up -d restarts only containers whose image changed.
It leaves everything else untouched.


--------------------------------------------------------------------------------
WATCHING LOGS
--------------------------------------------------------------------------------

    docker logs -f ai_doc_backend    # backend — watch model loading and requests
    docker logs -f ai_doc_frontend   # frontend
    docker logs -f ai_doc_mlflow     # MLflow server

Press Ctrl+C to stop following. The container keeps running.

The backend is ready when you see this line in its logs:
    INFO  main — Startup complete. Both models are loaded and ready.


--------------------------------------------------------------------------------
STOPPING AND STARTING
--------------------------------------------------------------------------------

    docker compose down        # stop and remove containers (data is preserved)
    docker compose up -d       # start everything again

    docker compose restart frontend-ui    # restart one service only


--------------------------------------------------------------------------------
TROUBLESHOOTING
--------------------------------------------------------------------------------

Container shows "exited":
    docker logs ai_doc_backend     # read the error
    docker compose up -d           # try restarting

"Top-level object must be a mapping" error:
    You are not in the project directory.
    Run:  cd ~   and try again.

"Connection refused" on localhost:9501:
    Either the tunnel is not open (re-run Step 1) or the frontend container
    has not started yet. Check:  docker compose ps

Port already in use:
    Another process on the server is using that port.
    Check which host port is mapped in docker-compose.yml and adjust your
    SSH tunnel accordingly.

Git conflict on git pull:
    cd ~
    git fetch origin && git reset --hard origin/newPlan
    This discards all local server changes and takes the remote version.
